WEEK 2 STUDENT SCORE CALCULATOR PRACTICAL

Files
- score_calculator.cpp: C++ program with four tests, score validation, highest score, grade, average, percentage, and pass/fail result.
- score_calculator.c: C version of the calculator with the same functionality.
- favourite_colour.c: Optional C bonus exercise.
- Week2_Practical_Report.pdf: Overview, example output, reflections, C/C++ comparison, and practice answer key.

Compile and run the C++ version
g++ score_calculator.cpp -o score_calculator
Windows: score_calculator.exe
macOS/Linux: ./score_calculator

Compile and run the C version
gcc score_calculator.c -o score_calculator_c
Windows: score_calculator_c.exe
macOS/Linux: ./score_calculator_c

Optional bonus
gcc favourite_colour.c -o favourite_colour
Windows: favourite_colour.exe
macOS/Linux: ./favourite_colour
