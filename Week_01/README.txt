WEEK 1 PROGRAMMING PRACTICAL SUBMISSION

Files
- about_me.cpp: Main C++ practical. It contains the six required prompts and all four C++ challenges.
- about_me.c: Companion C version based on the supplied C guide, including its listed extensions.
- Week1_Practical_Report.pdf: Project overview, example run, reflection answers, and submission evidence checklist.

Compile and run the C++ practical
g++ about_me.cpp -o about_me
Windows: about_me.exe
macOS/Linux: ./about_me

Compile and run the C companion
gcc about_me.c -o about_me_c
Windows: about_me_c.exe
macOS/Linux: ./about_me_c

The report identifies personal setup screenshots and checklist items that must be completed from the student's own computer and experience.
